# Portfolio · Santhosh V

Retro-terminal aesthetic (VT323 + DM Sans), narrative sections — not a resume dump. LeetCode stats refresh on each `npm run build`.

## Commands

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # fetches LeetCode GraphQL + static export
npm run preview
```

## Content

Edit **`src/data/site.ts`** — impact lines, platform/agent copy, contact links.

LeetCode logic: **`src/lib/leetcode.ts`** (fallback stats if API is down).
